# Brick Builder

Starter project for the unnamed voxel/brick creative webgame.

## Included now

- Dark, consistent UI
- Landing page
- Gallery page
- Creation detail page
- Functional Three.js / React Three Fiber builder
- Basic brick palette
- Color palette
- Starter-set counter
- Responsive layout
- PostgreSQL schema
- Vercel environment template

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
