Brick animation pipeline — drop on repo root.

User choice
  STATIC  (default) → GLB mesh only
  DYNAMIC           → GLB with clips on *_Mesh

Where
  Header next to export: STATIC | DYNAMIC then GLB / UNITY PACK
  Panel: same toggle under output lock 2D / 2.5D

Files produced
  STATIC:  name.glb  ·  name-unity.zip
  DYNAMIC: name-anim.glb  ·  name-unity-anim.zip

VOX / OBJ / PNG / JSON stay static formats.
